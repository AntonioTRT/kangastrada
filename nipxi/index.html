Projects / Battery testing

NIPXI battery test system

A configuration-driven PXI system for battery testing, instrument control, and measurement capture.

Problem

Coordinate a complex test station safely.

Battery testing brings together programmable instruments, relay switching, multiple channels, and measurement records. NIPXI organizes these functions for a station designed around eight battery positions and a shared hub board.

My contribution

Build modular control around the rack.

I developed configuration-driven device mapping, hardware lifecycle management, test sequences, relay control, safety monitoring, and SQLite/CSV measurement storage. NI instruments and relay drivers are kept behind hardware classes so test logic can work through shared interfaces.

Emergency shutdown disables and verifies the SMU output, then opens the relays. A low-current check gates relay switching.

Validation

Real rack checks without a battery.

Documented physical-rack checks include instrument discovery, SMU bench sourcing and readback, DMM voltage measurement, Numato Ethernet relay operation, and a Proto Test run through the production architecture without a battery connected.

Outcome and next step

Rack bring-up is ahead of battery-cycle validation.

The rack, relay path, safety mechanisms, and test infrastructure have been exercised. Real-cell charge/discharge performance has not yet been validated; multi-channel acquisition, temperature monitoring, and summary reporting remain unfinished.
